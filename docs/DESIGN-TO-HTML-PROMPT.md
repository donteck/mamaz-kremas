# Mamaz Kremas Design-to-HTML Master Prompt

Recreate the approved website design as a fully functional, responsive HTML/CSS/JavaScript website.

**IMPORTANT: The approved design image is the visual source of truth. Do not redesign, simplify, reinterpret, or replace the design.**

Match the design as closely as technically possible, including:

- Exact overall composition and section order
- Hero composition, proportions, spacing, and positioning
- All product and lifestyle photography
- Image crops and visual hierarchy
- Cream-to-image blending and soft gradient transitions
- Overlapping images, leaves, coconuts, decorative elements, and foreground objects
- Forest-green, kremas-cream, warm-brown, and restrained metallic-gold palette
- Luxury typography and font hierarchy
- Buttons, borders, cards, shadows, curves, dividers, and decorative gold details
- Navigation, announcement bar, logo placement, icons, and footer
- Every visible heading, paragraph, tagline, button, product, and section

## Image Quality Is Critical

Do not recreate an important photographic section using a small cropped image stretched with CSS. For complex visual compositions—especially the hero—use the actual approved artwork as the source when necessary to preserve its exact appearance.

Do not place strong CSS gradients, opacity layers, blur, or overlays over important photography if they reduce image clarity.

Images must remain sharp on large desktop displays.

Where the approved design intentionally blends photography into a cream or green background, reproduce that transition naturally using subtle masks/gradients without washing out the photograph.

## Do Not Lose Any Images

Create a self-contained version whenever practical. Embed required image assets directly into the HTML so opening or moving `index.html` does not cause missing images.

The finished page must still be a real website: use actual HTML for navigation, buttons, product information, sections, links, forms, and interactive elements. Do not simply display the entire website mockup as one giant screenshot.

For highly artistic portions of the design that cannot be faithfully reconstructed with normal HTML/CSS—such as the Mamaz hero composition—preserve the approved artwork while keeping appropriate interactive HTML elements functional.

Make the site responsive for desktop, tablet, and mobile without destroying the original visual identity.

## Final Visual QA

Before delivering, visually compare the finished HTML against the approved design. Check the hero first, then every section from top to bottom. Correct missing imagery, incorrect crops, spacing differences, colors, typography, blending, and proportions before considering the implementation finished.

**The goal is visual fidelity, not a new interpretation of the design.**

## Mamaz Kremas Identity

Preserve the Mamaz Kremas luxury identity exactly: Haitian heritage, premium tropical presentation, deep forest green, warm kremas cream, light brown, subtle gold, elegant editorial typography, high-end beverage photography, soft photographic blending, coconut/vanilla/cinnamon/tropical elements, and the sophisticated appearance of the approved Mamaz Kremas homepage.
